# legacy/v0.1 - 초기 프로토타입 (참고용)

프로젝트 초기에 급하게 만든 시제품 코드다. 지금은 정식 엔진(`gxpai/`)으로 옮겨졌고, 여기 코드는
"무엇을 어떻게 뽑았는지" 확인하는 참고 자료로만 남긴다. 실행 대상이 아니다.

의약품 공장(내용고형제) 도면에서 방과 기압 정보를 뽑던 최초 스크립트 세 개다.

| 스크립트 | 하는 일 | 옮겨진 위치 |
|---|---|---|
| `extract_rooms.py`    | 평면도에서 방 번호, 이름, 위치 추출 | `gxpai/ingest/extractors/floorplan.py` |
| `extract_pressure.py` | 차압 도면에서 기압, 화살표 추출 | `gxpai/ingest/extractors/pressure.py` |
| `merge_dataset.py`    | 위 둘을 방 번호로 병합 | `gxpai/core/run.py` |

## 회귀 기준

이 시제품이 뽑은 결과가 방 111개(3층 51개, 4층 60개)였다. 정식 엔진으로 옮긴 뒤에도 같은 111개가
나와야 제대로 이식된 것이므로, 이 숫자를 정답지(기준값)로 삼는다. 코드를 고칠 때마다 이 기준이
유지되는지 확인한다.

시제품의 원래 출력 파일(`master_rooms.json` 등)은 실제 방 이름이 들어 있어 고객 식별이 가능하므로
저장소에 올리지 않는다(`.gitignore` 처리).

## 하드코딩에서 설정으로

시제품은 레이어 이름("TEX" 등)과 거리 값이 코드에 박혀 있어서 그 공장 전용이었다. 정식 엔진에서는
이 값들을 전부 설정 파일(`profiles/osd_hs_2025.yaml`)로 옮겨, 다른 공장도 코드 수정 없이 처리되게
만들었다.
