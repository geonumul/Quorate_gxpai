## A. 이미 반영함 (done)

- **RASE 4연산자 규칙 스키마 + 근거 추적성** — RASE(w78-2011) · Wu RevisitACC · PRISMA review.
  규칙마다 requirement/applicability/selection/exception + clause. 위반에 근거 자동 첨부. → rules/gmp_osd_v1.yaml, engine.py.
- **규칙 동결 게이트(review: internal/unreviewed/approved)** — 레드팀 GEN-R2 · ML-ACC SLR(하이브리드).
  미검수 규칙은 잠금, 생성 보상 사용 금지. → rules YAML, test_rules_schema.
- **감사 등급 리포트: 근거조항 + 확인대기 상태 표시** — LLM ACC(Iversen) · Peng&Lin(warning) · PRISMA(추적성).
  위반→조항 추적, 잠긴 규칙·미결 질문 노출. → render/report.py.
- **화살표 기하 전 회전 검증(S-1)** — 우리 리스크. head_vector 전 사분면·임의각 회귀. → test_pressure_links.
- **검사 로직 순수함수 분리(생성 자기검증 재사용)** — RLVR(검증가능보상) · MedBuild(규칙엔진 격리). → checks/_model.

## B. 지금 착수 가능 (데이터·IP·심판 무관)

- **위반 상태에 'insufficient-information / transfer(전문가)' 정식 추가** — PRISMA · RASE(Transfer) · Peng&Lin(warning).
  현재 pass/fail만. 데이터 부족 시 non-compliant로 뭉개지 말고 별도 상태(선행연구 공통 경고). 작업량 작음.
- **check-rule 4범주 태그(class1 명시값/class2 파생/class3 구조/class4 해존재)** — Peng&Lin · Solihin-Eastman(Wu).
  규칙마다 복잡도 등급 태그 → 구현 난이도·리스크 예측, 결정론 실행 범위 명확화. rules YAML 필드 추가.
- **규정변환 트리아지(Translate/Transform/Transfer) 문서화** — RASE(w78-2011).
  명확조항=직접 룰화, 모호=재작성 후 룰화(변경 투명기록), 성능기반·주관=전문가 라우팅. GMP는 Transfer 많음.
- **반사실(counterfactual) 최소수정 설명** — XAI(향후_아이디어). 위반 evidence 에 "무엇을 최소로 바꾸면 통과"
  추가. 결정론 규칙이라 정확 산출. (사용자 지시로 현재 보류 - 재개 시 여기.)
- **LBL 정규화 정밀화** — 우리 발견. `[\s()N\-]` 가 대문자 N 을 어디서든 제거(false negative). `(N)` 접두만
  제거하도록 좁히기. 카나리아 재확인 필요(사용자 판단 대기).

## C. 심판(검증 엔진) 완성 후 / 생성 단계

- **인접을 nearest-k → accessibility 4엣지(문/개구부/접함/계단)로 승격** — IFC GNN(energies) · SAGE-E(엣지피처).
  거리 근사보다 GMP 차압·오염관리에 정합. 단 문·개구부 인식(경계) 선행 필요 → 경계 확보 후.
- **우도 기반 이상탐지 = 위반 후보 자동 플래깅** — ATISS · COFS. 생성/학습 모델의 저우도 객체를 규정 위반
  후보로 표시. 생성 단계 도입 시.
- **추출 품질 지표: arc-length IoU / PQ** — FloorPlanCAD · GAT-CADNet · SymPoint. 경계·심볼 인식 품질을 정량
  측정. 경계 확보 후.
- **정수 그리드 기하 커널(float 불안정 회피)** — MedBuild · GSDiff(이산좌표) · CDCL(300mm 모듈). 배치·경계 연산
  안정성. 생성 단계.
- **X-42 왕복 검증(생성→역추출→스펙 대조)** — 레드팀 X-42. 생성기와 추출기가 서로 검증. 생성 단계.
- **퇴화 검출기 배터리(형상비·전실수·복도비율)** — 레드팀 GEN-R1. 보상해킹 방어. 생성 단계.
