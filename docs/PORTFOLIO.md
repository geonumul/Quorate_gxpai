# PORTFOLIO — 포트폴리오 산출물 트래킹 (PART E)

납품물과 포트폴리오 산출물을 분리 관리. 고객 데이터 노출분은 전부 익명화/합성 버전 병행.

## 산출물 체크리스트
- [ ] 아키텍처 다이어그램 (Stage 1~5 계층 + zip→DB→Neo4j→violations→생성→DXF)
- [ ] 정량 지표 표 (파이프라인 자동 산출: 라벨 매칭률 94/111, boundary율, violations 정밀도, 온보딩 소요시간, 생성 루프 수렴 횟수)
- [ ] before/after 비주얼 (실도면 익명 SVG vs 검증 마커 vs 생성 배치안)
- [ ] 합성 데모 시설 (tests/fixtures/synthetic 확장 — 공개 리포 데모)
- [ ] 기술 글 1편 ("GxP 도면의 온톨로지화 — DXF에서 지식그래프, 규칙 검증까지")
- [ ] 연구 접점 메모 (그래프 학습 / 건설안전 XAI 연계)

## 공개 범위 규약 (E.2)
- 공개: 엔진 코드 + 합성 데모 + 문서 (고객명/실도면/실 방이름 전부 제거)
- 비공개: raw/, artifacts/, 고객 식별 가능 프로파일 값
- ⚠ 발주처와 포트폴리오 사용 허락 **서면 사전 합의** (question 테이블 항목 추가) — 마감 후 분쟁 예방

## "완성" 정의 (E.3)
- [ ] 신규 zip → 코드수정 0줄 → 리포트, 실측 1회 이상
- [ ] violations 6종 이상 + 컨설턴트 근거 검수 1회 반영
- [ ] 자가검증 루프로 critical 0 배치안 + DXF 출력
- [ ] 합성 데모로 재현되는 공개 리포
- [ ] 지표 표 + 기술 글 + 다이어그램 완비
