## 플래그 (설계급 - 사용자 확인 후)

- **M6/M7 멱등성·감사추적 정직성**: 문서엔 "run 단위 delete+reinsert 멱등"이라 했으나 run_id 가 매번
  새로 발급돼 `DELETE FROM room WHERE run_id` 는 항상 0행(사실상 append-only). 또 `run.status` 는
  한 트랜잭션 안에서 running→done 이라 실패 시 run 행 자체가 롤백돼 'failed' 가 안 남음. → 실패 이력이
  감사에 안 남는다. 개선안: run 행을 payload 와 별도 트랜잭션으로 커밋(running/failed 관측 가능), 또는
  문서를 append-only 로 정정. **GMP 감사 요구와 직결 - 방향 결정 필요.**
- **M8 파생 데이터가 run 트랜잭션 밖**: adjacency/pressure_links.build 가 status='done' 커밋 후 별
  커넥션에서 실행 → 이들이 실패해도 run 은 'done'. 원자성 깨짐. 개선안: 한 트랜잭션으로 묶거나 done 을
  파생까지 끝난 뒤 스탬프.
- **M3 중복 room_no 조용한 덮어쓰기**: `_merge` 가 같은 room_no 를 말없이 덮음(현 데이터 111 클린이라
  미발생). DB uq_room_run_no 가 잡을 것을 dict 가 먼저 삼킴. 개선안: 중복 감지 시 경고/기록.
- **LBL 정규화 과도한 'N' 제거**: 이미 별도 플래그(false negative 위험). `(N)` 접두만 제거로 좁히기.
- **차압도 방귀속 재검증**: pressure_links 가 head/tail(관찰기하)만 채우고 room_high/low 는 NULL 유지.
  발주처 "화살촉=저압" 확인 후 승격 시, 위 화살표 귀속 수정이 반영됐는지 재확인할 것.

## 확인했으나 문제 아님(클리어)

- 커넥션: psycopg with 블록으로 닫힘/롤백 - 누수 없음. FK insert 순서 정상.
- 게이트 기본값: config/enabled 누락 시 비활성(0건) - 카나리아 PRES/ADJ 0 일치.
