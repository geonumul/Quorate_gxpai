## 고침 - 감사추적 (2026-07-03, migration 006 + run.py)

- **M6/M7 멱등성·감사추적 정직성 [고침]**: run 행을 payload 와 **별도 트랜잭션으로 먼저 'running' 커밋**
  → 실패해도 run 이력이 남음. **실패 시 'failed' + finished_at + error 기록**(migration 006 컬럼 추가).
  죽은 `DELETE FROM room WHERE run_id` 제거. docstring 을 append-only(불변 이력=감사에 올바름)로 정정.
  검증: running→failed 지속, done 마감 확인. 카나리아 111/3/17 불변, 46 통과.
- **M8 파생 데이터가 run 트랜잭션 밖 [고침]**: adjacency·pressure_links.build 를 **성공 판정 안으로** 이동
  → 파생까지 끝나야 'done', 중간 실패 시 'failed'. (완전 원자성은 아니나 'done'=전부 완료 보장.)

## 플래그 (설계급 - 사용자 확인 후, 잔여)
- **M3 중복 room_no 조용한 덮어쓰기**: `_merge` 가 같은 room_no 를 말없이 덮음(현 데이터 111 클린이라
  미발생). DB uq_room_run_no 가 잡을 것을 dict 가 먼저 삼킴. 개선안: 중복 감지 시 경고/기록.
- **LBL 정규화 과도한 'N' 제거**: 이미 별도 플래그(false negative 위험). `(N)` 접두만 제거로 좁히기.
- **차압도 방귀속 재검증**: pressure_links 가 head/tail(관찰기하)만 채우고 room_high/low 는 NULL 유지.
  발주처 "화살촉=저압" 확인 후 승격 시, 위 화살표 귀속 수정이 반영됐는지 재확인할 것.

## 확인했으나 문제 아님(클리어)

- Cypher: 전부 named parameter - 인젝션 없음.
- 커넥션: psycopg with 블록으로 닫힘/롤백 - 누수 없음. FK insert 순서 정상.
- 게이트 기본값: config/enabled 누락 시 비활성(0건) - 카나리아 PRES/ADJ 0 일치.
