# 향후 시도해볼 아이디어 (미확정, 메모 수준)

지금 당장 하는 일은 아니고, "이런 것도 시도해볼 만하다" 수준으로만 적어 둔다. 실제 착수는 그때
가서 검토·결정.

## XAI - 반사실(counterfactual) 설명
- 아이디어: 위반에 "왜"뿐 아니라 **"무엇을 최소로 바꾸면 통과하나"**를 붙인다.
  예: "PRES-001 위반 → 방 X 압력을 Y보다 높이면 해소" / "ADJ-001 → 방 A를 D구역에서 떼면 해소".
- 왜 우리에게 맞나: 규칙이 결정론적이라 위반된 제약의 여유분에서 최소 수정을 정확히 뽑을 수 있다.
  블랙박스가 필요 없고 감사에도 그대로 통함. 3단계 생성에서 "0위반까지 최소 수정 반복"에 재사용 가능.
- 주의: SHAP/LIME 같은 사후 설명은 블랙박스 부품(4단계 LLM/선호모델)이 생겼을 때만, 사람이 검증하는
  보조로만. 핵심 판정은 유리상자(규칙)로 유지 - XAI로 블랙박스를 정당화하지 말 것.
- 착수 후보: violation.evidence 를 최소수정 제안으로 확장(작업량 작음). 3단계 골격과 함께.

## 3단계 생성 - 규칙엔진을 채점기로 쓰는 제약 최적화
- 딥러닝 RL 대신 제약 최적화(OR-Tools 등) + 순수함수 evaluate 를 자동 채점기로.
- RL은 시설 1개·수정이력 0·설명책임 때문에 아직 부적합. 학습은 사람 검토 라벨(review_status,
  violation.status=false_positive, room.confidence)이 쌓인 뒤 모방/선호학습으로.
