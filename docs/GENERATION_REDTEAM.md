# PART 11. 심판(violations 엔진 = 보상 함수) 자체를 의심하라

**GEN-R1. 보상 해킹 / Goodhart의 법칙 [필수] 작전 전체의 아킬레스건**
"critical 0건"을 목표로 최적화하면 시스템은 규칙의 **구멍**으로 수렴한다. 예측되는 퇴화해:
- 모든 방을 복도 하나에 일렬로 매달기 (인접 규칙 전부 만족, 설계로는 쓰레기)
- 전실(에어락) 남발 — 갱의 체인, 압력 규칙을 전실 도배로 기계적 만족
- 극단 세장비 방 (1m × 40m 보관실 — 면적 제약 만족)
- 검사 안 하는 차원으로 도망: 동선 총연장, 기둥 모듈 정합, 창/외벽, 시공성은
  현 규칙에 없으므로 **무한히 나쁠 수 있다**
→ 대응: (1) **퇴화 검출기(degeneracy detector)를 보상과 별도로 상시 가동** — 형상비 상한(1:4),
전실 수 상한(존당 k개), 복도 면적 비율 상한(25%), 방 정렬 엔트로피 하한.
(2) 보상 = 규칙 통과(hard) × 품질 점수(soft: 동선, 형상, 레퍼런스 유사도) 곱 구조 —
합이 아니라 곱이어야 한 축 포기 전략이 봉쇄된다. (3) 규칙 커버리지 문서화: "엔진이 보지 않는 것"
목록을 명시하고, 그 축들은 인간 평가(G3)가 담당함을 아키텍처에 못박는다.

**GEN-R2. 규칙 오류의 증폭 학습 [필수]**
화살표 방향(S-1) 같은 규칙 오류가 남은 채 RL을 돌리면, 모델이 **오류를 진리로 학습**하고
수만 개 합성 데이터에 오류가 각인된다. 나중에 규칙을 고쳐도 모델, 데이터는 오염된 채다.
→ 대응: **규칙 동결 게이트** — 심층검증 필수 항목 + 컨설턴트 근거 검수 1회를 통과한
규칙 버전(rules@vN)만 보상으로 사용. 합성 데이터에 rules 버전 스탬프, 규칙 개정 시
해당 버전 데이터 전량 재검증(통과분만 유지).

**GEN-R3. 부분 평가(incremental check) 불일치 [권장]**
Track E용 부분 배치 평가가 전체 평가와 다른 판정을 내면(부분에선 OK → 완성하니 위반)
탐색이 배신당한다. → 대응: incremental 평가는 "위반 확정"만 반환(조기 가지치기),
"통과"는 절대 반환하지 않는 admissible 설계. 완성 시 full check 필수.

**GEN-R4. severity 가중치의 임의성 [권장]**
critical/major/minor 가중이 보상 스케일을 좌우하는데 근거가 없다.
→ 대응: 가중치를 하이퍼파라미터로 명시, 기록하고, 민감도 분석(X-36 승계)을 보상에도 적용 —
가중치 ±50%에 랭킹이 뒤집히는 후보는 "경계 후보"로 태깅.

# PART 12. 트랙별 공격 (A~F 전수)

## Track A (CP-SAT) 공격
**GEN-A1. 그리드 해상도 딜레마 [필수]**: mm 단위 정수변수 = 변수 폭발, 1m 조대화 = 문폭(0.9m), 벽두께 표현 불가. → 대응: **300mm 모듈 그리드**(건축 모듈 정합, 문=3칸) 기본 + 후처리 연속 완화.
해상도는 프로파일 파라미터로.

**GEN-A2. 복도 연결성은 CP-SAT의 사각지대 [필수] 기술적 최대 함정**
"모든 방이 복도망으로 연결"은 그래프 연결성 제약 — 선형/불리언으로 자연 표현이 안 되는
대표적 난제다. 방 배치는 풀리는데 복도가 안 이어지는 해가 쏟아질 것.
→ 대응 3단: (1) **복도 골격 선결정** — 레퍼런스 아키타입의 복도 위상(물류축형/중앙코어형,
발주처 워크플로우 6단계와 동일 개념)을 먼저 고정하고 방을 복도에 붙이는 순서로 문제 재정의
(연결성이 구성적으로 보장됨), (2) flow 기반 연결성 인코딩(각 방→출구 단위 유량)은 크기 폭발
주의하며 소규모만, (3) 사후 연결성 검사 + 불통 시 복도 골격 변형 재시도.

**GEN-A3. 대칭성 폭발 [권장]**: 동일 크기 방 n개의 순열 n!이 탐색을 죽인다.
→ 동종 방 그룹에 사전식 순서 강제(symmetry breaking), solver 힌트로 레퍼런스 배치 주입.

**GEN-A4. 위계분해의 경계 손실 [권장]**: 존 단위 최적화가 존 경계에서 갱의 체인을 끊는다.
→ 존 분할 시 체인 관련 방들을 같은 존으로 묶는 사전 클러스터링 + 경계 방은 2존 공유 변수로.

**GEN-A5. L자/비직사각 방 표현 불가 [편집증→Wave2 필수]**: 직사각 가정이 실도면과 괴리
(실도면엔 ㄱ자 방 존재). → v1은 직사각 한정 명시, Wave 2에서 직사각 2개 합성으로 확장.

**GEN-A6. timeout 시 무해(no solution)와 부분해 구분 [필수]**: infeasible인지 시간부족인지
로그로 구분해 기록. 진단 모드(R-E5)가 여기 물린다.

## Track B (CBR) 공격
**GEN-B1. 그래프 유사도 비용 [권장]**: GED는 NP-hard. → WL-kernel/GNN 임베딩 근사 +
상위 후보만 정밀 비교. N<10인 동안은 전수라 무관 — 문제 되기 전에 근사기 준비만.

**GEN-B2. 아키타입-요구 충돌 [필수]**: 레퍼런스는 방 50개인데 요구는 100개면 위상 이식이 깨진다.
→ 아키타입을 통째가 아니라 **모티프 단위**(갱의 체인 모듈, 세척 클러스터, 포장 라인 모듈)로
분해 저장 — 모티프 조합으로 규모 확장. 온톨로지 스키마에 Motif 노드 추가.

**GEN-B3. 단일 설계사 스타일 고착 [편집증]**: N이 늘어도 같은 설계사 도면만 쌓이면 다양성 착시.
→ 시설 메타에 설계사 필드, priors 계산 시 설계사별 층화.

## Track C (신경 생성) 공격
**GEN-C1. 합성 데이터의 solver 편향 [필수]**: CP-SAT 해는 탐색 순서 편향(구석 몰림, 첫 해 유사).
이대로 학습하면 모델이 "solver 버릇"을 배운다. → 대응: random branching + solution pool 다중해 +
objective 랜덤 교란으로 해 다양화, 다양성 지표(pairwise graph distance 분포)를 데이터 QC로.

**GEN-C2. 학습 일정, 비용 현실 [필수]**: 벡터 디퓨전 학습은 Wave 2 4주 안에 안정화 안 될 확률이
높다(표현 설계, 정규화, 가변 방 수 처리 전부 연구 이슈). → **Track C를 Wave 2 필수에서 제외하고
논문 트랙으로 공식 이관**하는 트리거 명시: W2 개시 2주 내 학습 곡선 미개선 시 이관.
납품 서사는 A+B+D+F로 이미 성립한다.

**GEN-C3. 평가 지표 부재 [필수]**: FID는 래스터용. 우리 3축 지표를 처음부터 정의 —
(a) 준수율(critical/major 통과), (b) 다양성(후보 간 그래프 거리), (c) 현실성(실도면 통계와의
분포 거리: 방 면적/형상비/인접 차수 분포의 Wasserstein). 이 3축 자체가 논문 기여가 된다.

**GEN-C4. model collapse (자기 증류 오염) [필수]**: 자기 생성물 재학습 루프는 분포 축소로
퇴화한다는 것이 확립된 결과다. → 재학습 데이터에 CP-SAT 신규 합성분 + 실도면을 매 라운드
고정 비율(예: 5:3:2 = solver:실:자기생성) 혼합, 라운드마다 GEN-C3 지표로 퇴화 감시.

## Track D (LLM) 공격
**GEN-D1. LLM은 좌표 산술을 못 한다 [필수]**: JSON 폴리곤을 직접 뱉게 하면 겹침, 틈이 난무한다.
→ LLM의 역할을 **이산 결정**(어느 방을 어느 존, 어떤 순서, 어떤 모티프)으로 한정하고
연속 좌표는 CP-SAT/후처리가 담당하는 **분업 구조**. LLM 출력에 좌표 스냅+겹침 해소 후처리 필수.

**GEN-D2. self-refine 진동/비수렴 [필수]**: 피드백 루프가 A위반↔B위반을 왕복할 수 있다.
→ 위반 이력 누적 제시("이전에 이 수정으로 저 위반이 생겼다"), 최고 후보 보존(elitism),
루프 상한 5회 + 최종은 Track F 수리로 인계.

**GEN-D3. sparse reward [필수, RLVR 시]**: 방 60개에서 critical 0은 초기엔 거의 안 나옴 →
학습 신호 0. → 커리큘럼(방 5→15→30→60) + 위반 수 감소량 기반 shaped reward + Track A 해를
SFT 웜스타트로.

**GEN-D4. 토큰 한계 [권장]**: 방 60개 × 폴리곤 좌표 JSON이 컨텍스트를 압박.
→ 좌표를 그리드 인덱스로 압축, 존 단위 분할 생성.

## Track F (repair) 공격
**GEN-F1. 두더지잡기(whack-a-mole) [필수]**: 국소 수리가 이웃에서 새 위반을 만든다.
→ 수리 반경 점증 정책(1-hop→2-hop→존 전체), 총 수리 라운드 상한(3), 라운드마다 전역 재검증,
위반 수가 늘면 즉시 롤백.

**GEN-F2. 수리의 품질 파괴 [권장]**: 합법이지만 동선이 길어진 해로 밀려남.
→ 수리 목적함수에 원안과의 변경 최소화 항(이동 방 수 페널티) 포함.

# PART 13. 플라이휠, 데이터 공격

**GEN-W1. 컨설턴트 diff의 수취 현실 [필수] 운영상 최대 허들**
컨설턴트는 AutoCAD로 수정한다 — 우리 레이어 체계가 깨진 DXF가 돌아온다. diff 추출이
"수정 전후 재-ingest + 방 단위 매칭"이라는 또 하나의 파이프라인임을 인정하고 설계에 포함.
→ 출력 DXF에 room_no를 XDATA(확장 엔티티 데이터)로 심어 수정 후에도 추적 가능하게 —
**지금 export 설계에 반영해야 나중에 공짜**.

**GEN-W2. 선호 데이터의 평가자 노이즈 [권장]**: 컨설턴트마다 스타일이 다르다 —
한 명의 수정을 진리로 학습하면 개인 취향을 배운다. → diff에 평가자 ID 기록, 복수 평가자
합의분만 강신호로, 단독 수정은 약신호 가중.

**GEN-W3. PlanSpec 샘플러의 대표성 [권장]**: 합성용 요구조건 자체가 비현실적이면(방 200개 OSD)
쓰레기 대량생산. → 샘플러의 사전분포를 실도면 통계 + 발주처 과거 프로젝트 유형
(소개서 실적 113건의 시설 유형 분포)에 앵커.

# PART 14. 평가(G3), 조직, 법률 공격

**GEN-L1. 레퍼런스 도면의 저작권/설계권 [필수] 기술 밖 최대 리스크**
학습, 변형의 원료인 실도면의 저작권은 **원 설계사무소**에 있을 가능성이 높다 (발주처가 소유권을
가졌는지, 사용 허락 범위에 "파생 설계 생성"이 포함되는지 불명). Track B(변형)와 Track C/D(학습)의
법적 지위가 다르다는 점도 주의.
→ 대응: question 최우선 등록 — "제공 도면의 권리관계와 AI 학습, 변형 사용 범위 서면 확인".
확인 전까지 Track B는 위상 통계(아키타입)만 사용하고 기하 복제 금지, Track C/D 학습은
합성 데이터 중심으로. **포트폴리오 공개는 합성 데모만**(기존 규약 승계).

**GEN-L2. 외부 API로의 고객 도면 전송 [필수]**
Track D 1단계(self-refine)가 레퍼런스 요약, 방 목록을 외부 LLM API로 보낸다 — 발주처/원청과의
계약에 데이터 반출 금지 조항이 있으면 위반이다.
→ 대응: 서면 확인 전까지 API에는 **익명화 스키마만**(방이름→타입 코드, 좌표 정규화, 시설명 제거)
전송. 확인 후에도 전송 데이터 로그 보관.

**GEN-E1. 블라인드 평가의 탈맹검 [필수]**
카톡방 실사례가 증명한다 — 업계 사람은 평면만 보고 어느 회사 도면인지 알아본다. 컨설턴트가
실도면을 알아보는 순간 블라인드가 깨진다. → 실도면도 익명화, 재렌더링(동일 스타일 SVG)해서
생성안과 시각적으로 구분 불가하게 제시, 평가 후 "어느 것이 실도면 같았나" 역질문으로 맹검 성공률 측정.

**GEN-E2. 평가 통계력, 루브릭 [필수]**: 3인 × 소수 표본은 검정력이 없다. "수정 후 사용 가능"도 모호.
→ 5점 루브릭(치명 결함/대수정/중수정/소수정/즉시 사용) 사전 정의 + 평가자 간 일치도(κ) 보고 +
표본 수 최소 20안. 유의성 주장 대신 신뢰구간 보고로 정직하게.

**GEN-O1. 기대 관리 [필수]**: "AI가 도면을 그린다"로 팔리면 첫 시연에서 기대가 붕괴한다.
→ 모든 시연, 문서에서 통일 문구: "규정 위반 0건이 **검증으로 보증된** 배치 초안 K개를 분 단위 생성".
계획서의 99.9% 정확도류 수치와 우리 지표의 관계를 발주처와 사전 정렬(그 수치는 우리가 정의한
지표가 아님을 명시).

**GEN-O2. 일정 낙관 편향 [필수]**: Wave 1 "2주"는 CP-SAT 배치기 단독으로도 빠듯하다.
→ Wave 1 내부 우선순위 고정: W1.1(CP-SAT)+W1.5(투영기)가 최소 시연 단위 —
이 둘만으로도 "요구→합법 배치→3종 도면"이 성립. W1.2~4는 순차 증강. 지연 시 잘리는 순서:
W1.3(LLM 루프) → W1.2(아키타입) → W1.4(repair).

# PART 15. 생성 전용 교차검증 목록 (기존 80항목에 추가)

- **X-42 [필수] 요구 왕복(round-trip)**: 생성 배치 → 역추출(우리 ingest 파이프라인!) → PlanSpec
  재구성 → 원 요구와 diff = 0. **생성기와 추출기가 서로를 검증하는 구조** — 이 프로젝트만의 무기
- **X-43 [필수] 생성물에 verify 전항목 적용**: 생성 DXF도 실도면과 동일하게 80항목 통과 의무
  (겹침 0, 커버리지, 압력 DAG, 층간 정합...)
- **X-44 [필수] 퇴화 검출기 배터리**: GEN-R1의 형상비/전실 수/복도 비율/정렬 엔트로피 — 후보 풀
  단계에서 자동 탈락
- **X-45 [필수] 재현성**: 동일 PlanSpec + seed → 동일 후보 K개 (전 트랙 seed 고정)
- **X-46 [권장] metamorphic 검증**: PlanSpec에 방 1개 추가/면적 10% 변경 → 출력 변화가 국소적
  이어야 함(전역 재편이면 불안정 신호). 요구 축소 → 위반 수 비증가 단조성
- **X-47 [권장] 다양성 하한**: 후보 K개의 pairwise 그래프 거리 중앙값 하한 — K개가 사실상
  1개(복제)면 실패로 판정
- **X-48 [권장] 현실성 분포 검사**: 생성물의 면적/형상비/인접 차수 분포 vs 실도면 분포
  Wasserstein 거리 임계 (GEN-C3의 c축을 개별 후보에도 적용)
- **X-49 [권장] 교차 트랙 대조**: 같은 PlanSpec을 Track A와 D에 독립 투입 → 존 구성이 크게
  다르면 스펙이 미결정(under-specified)이라는 신호 → 스펙 보강 질문 자동 생성
- **X-50 [편집증] 적대적 PlanSpec 세트**: 일부러 모순 요구(면적 합 > 외곽 면적, 불가능 인접 조합)
  주입 → 시스템이 "생성 실패+원인"을 정확히 보고하는지. **불가능을 불가능이라 말하는 능력도
  제품 기능이다** (컨설턴트 신뢰의 원천)
- **X-51 [편집증] 보상 해킹 honeypot**: 규칙 하나를 의도적으로 느슨하게 만든 실험 브랜치에서
  RL이 그 구멍으로 수렴하는지 관찰 — 수렴하면 GEN-R1 방어선이 약하다는 실증

# 종합: 작전 v1.0에서 수정되는 것

1. 보상 = hard 통과 × soft 품질 **곱** 구조 + 퇴화 검출기 상시 가동 (GEN-R1)
2. **규칙 동결 게이트** 도입 — 검증 통과 규칙 버전만 보상 사용 (GEN-R2)
3. Track A는 **복도 골격 선결정** 방식으로 문제 재정의 (GEN-A2) + 300mm 모듈 그리드 (GEN-A1)
4. Track B는 아키타입을 **모티프 단위로 분해** 저장 (GEN-B2), 권리 확인 전 기하 복제 금지 (GEN-L1)
5. Track C는 Wave 2 필수에서 **조건부 이관 트리거** 명시 (GEN-C2), 3축 평가지표 선정의 (GEN-C3)
6. Track D는 LLM=이산 결정 / 좌표=solver **분업 구조**로 (GEN-D1), API 전송은 익명화 스키마만 (GEN-L2)
7. export DXF에 room_no XDATA 삽입 — 컨설턴트 diff 회수의 전제 (GEN-W1)
8. G3 평가는 익명화 재렌더링 + 루브릭 + κ 보고 (GEN-E1/E2)
9. 교차검증 X-42~51 십종 추가 — 특히 X-42(왕복)와 X-50(불가능 보고)은 제품 기능으로 승격
10. 법률 질문 2건(저작권, 데이터 반출)을 question 최우선으로 — **코드보다 먼저 답을 받아야 하는 항목**
