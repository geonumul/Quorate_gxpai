# 데이터 대기 작업 (Data-Blocked Backlog)

이 문서는 "코드는 준비됐지만 발주처 데이터/확인이 있어야 켤 수 있는" 작업을 추적한다.
데이터가 오면 여기 적힌 "활성화 방법"만 따르면 되도록, 미리 만들어 시험까지 끝낸 상태로 둔다.

- 무엇을 요청해야 하는지: `docs/발주처_요청사항.md`
- 진행 상태 전반: `docs/PROGRESS.md`
- **기존 데이터로 밝혀낸 것(발주처 자료 없이)**: `docs/기존데이터_분석.md` - TA 단위·화살표 의미·좌표계.
- 원칙: 리스크 S-1 "3중 확인 전 규칙 가동 금지". 확인 전에는 게이트(enabled:false)로 잠가 둔다.

---

## B-1. PRES-001 압력 캐스케이드 역전 (규칙, 게이트 상태)

- 상태: **코드·순수 로직 완성 + 합성 시험 통과. 게이트 잠김(rules/gmp_osd_v1.yaml → PRES-001.config.enabled=false).**
- 하는 일: 차압 화살표가 가리키는 고/저압 방향과 방 청정등급을 맞대어, 더 깨끗한 방이
  오히려 저압 쪽이면 위반(critical)으로 잡는다.
- 막는 데이터/확인:
  1. **화살표 의미 확인**(S-1): 화살촉이 "고압→저압"을 뜻하는지. 발주처 요청 A-5.
     - **업데이트(기존데이터_분석.md)**: 방향 그래프 98% 일관 + 계단/샤프트가 전부 도착점 →
       "화살촉=저압 쪽"이라는 **우리 측 잠정 추정**의 근거. 단 확정 아님(보류) - 발주처 확인 필요.
       혼자 정할 사안이 아니므로 상태는 계속 "확인 필요"로 둔다.
     - 화살표→방 귀속은 차압도 내부 라벨로 우회 가능(방 위치 보존 코드만 추가하면 됨). 현재는
       pressure_relation.room_high/room_low 가 NULL, approx=true.
  2. **Grade 도면**: 방별 청정등급(A/B/C/D 등). 발주처 요청 A-1. (room.grade 현재 NULL)
  3. **컨설턴트 검수**: grade_rank(등급 서열)와 "깨끗한 방=고압" 방향이 이 시설 기준에 맞는지.
- 활성화 방법(데이터 도착 후):
  1. 화살표→방 귀속 로직으로 pressure_relation 채우기(room_high/low 설정, approx=false).
  2. Grade 추출기로 room.grade 채우기.
  3. rules/gmp_osd_v1.yaml 의 PRES-001.config.enabled 를 true 로, grade_rank 를 검수값으로.
  4. `gxpai validate` 재실행 → 위반 검토.
- 순수 로직 시험: tests/test_compliance_rules.py::test_pres001_* (역전 검출·approx/미상 건너뜀·게이트).

## B-2. ADJ-001 Grade 인접 금지쌍 위반 (규칙, 게이트 상태)

- 상태: **코드·순수 로직 완성 + 합성 시험 통과. 게이트 잠김.**
- 하는 일: 직접 인접이 금지된 청정등급 조합(예: A-D)이 맞닿으면 위반(critical).
- 막는 데이터/확인:
  1. **Grade 도면**: 방별 청정등급. (room.grade NULL)
  2. **컨설턴트 검수**: forbidden_pairs(금지 등급쌍)가 맞는지.
  3. **정밀 인접**: 현재 인접은 최근접-k 근사 → 방 경계 폴리곤 승격 후 재검증 필요(오탐/누락 방지).
- 활성화 방법: room.grade 채우고, forbidden_pairs 검수 후 ADJ-001.config.enabled=true.
- 순수 로직 시험: tests/test_compliance_rules.py::test_adj001_* (금지쌍 검출·양방향 중복제거·게이트).

## B-3. PRES-002 차압 기준값 미달 (규칙, 미착수)

- 상태: **미구현.** 잠정 수치(예 15Pa)가 이 시설에 맞는지 몰라 스펙만 있음.
- **업데이트(기존데이터_분석.md)**: TA 값(90~300, 이산군집)은 분석 결과 **차압(Pa)이 아니라 풍량(CMH) 계열**.
  즉 **TA 값으로는 PRES-002 를 만들 수 없다.** 실제 방 사이 차압(Pa) 수치가 도면/설계서 어디에 있는지
  발주처에 별도 확인 필요.
- 막는 것: 실제 Pa 차압 수치 소재 확인 + 기준 차압값 컨설턴트 검수.
- 착수 조건: Pa 차압 데이터 확보되면 순수 로직 작성(PRES-001 패턴 재사용) + 합성 시험 후 게이트로 추가.

## B-4. ADJ-002 갱의 체인 누락 (규칙, 미착수)

- 상태: **미구현.** 청정구역 진입 경로에 규정 갱의실 시퀀스가 있는지 검사.
- 막는 것: Grade 도면(구역 정의) + 경로/인접 정밀도(폴리곤) + 갱의 시퀀스 규정 검수.
