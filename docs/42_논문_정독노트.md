# 선행연구 정독 노트 (35편 전문 정독, 2026-07-03)

논문 원문 PDF는 상위 `Quorate/논문/` 폴더(git 밖). 이 문서는 전문(초록 아님) 정독 후 방법, 수치, GXPAI
적용점을 요약한 것. 큐레이션, 링크: `30_생성단계_설계/GXPAI_선행연구_자료총람.md`(구 큐레이션+논문링크 통합).

중복 정리: 원본 45개 → **35개**(해시 동일 7 + Elsevier PII 동일 2 + 내용 동일 1 = 10개 삭제).

## 관통하는 결론 (35편 공통)
1. **순수 자동화(하드코딩 룰)도 순수 ML/LLM도 GMP, 인허가엔 불충분 → 결정론 규칙엔진(감사가능) + AI(GNN/LLM) 보조 하이브리드**가 전 분야 공통 결론.
2. **LLM은 좌표산술, 수치판정에 약함** → LLM=이산결정/해석/초안, 좌표, 판정=결정론 코드(솔버/규칙). 우리 GEN-D1과 동일.
3. **인접, 관계(엣지), 위상 모델링이 규정검증과 생성의 핵심**. 노드 속성만으론 부족.
4. **데이터 부족은 합성데이터로, 재현성, 감사성은 사람 게이트로** 방어. GMP 도면은 전 논문 도메인(주거/상업)과 갭 → 사전학습→소량 파인튜닝 또는 후보생성+규칙검증.
5. 생성 논문 다수가 **하드제약을 보장 못 함**(소프트 손실/프롬프트 수준) → 생성 후 **검증, repair 레이어 필수**(우리 강점).

## A. 벡터 CAD 심볼인식 (Stage 1 추출, Stage 2 온톨로지)

- **FloorPlanCAD** (CVPR2021, 2105.07147, 데이터공개): 실제 벡터CAD 1.5만장, 35클래스 panoptic 벤치마크.
  엔티티=그래프노드(끝점 인접 ε=100mm, 평행선 벽 특수처리)+CNN텍스처. arc-length IoU, PQ 지표.
  → 벡터→그래프 파이프라인, 평가지표를 우리 DXF 추출/온톨로지에 이식. GMP 심볼 재주석 필요.
- **GAT-CADNet** (CVPR2022, 2201.00625, 코드X): 8-stage GAT + RSE(상대공간인코딩)+CEE(인스턴스=인접행렬예측).
  PQ0.737. 정점 4096 제한(대형도면 분할필요). → 그래프-온톨로지 설계 근거.
- **SymPoint** (ICLR2024, 2401.10556, **코드공개**): 프리미티브=포인트클라우드, PointTransformer+Mask2Former.
  PQ83.3(GAT-CADNet +9.6p). → **심볼인식 백본 채택 1순위**(공개코드 fine-tune). 1000epoch 학습비용.
- **CADSpotting** (2025, 2412.07377, 데이터공개예정): dense point sampling(타입/레이어 무의존=실무 강건)
  +SWA(슬라이딩윈도우, 대형도면). PQ87.4, LS-CAD(≥1000㎡). 벽폴리곤/문/창 파라미터 자동추출.
  → **레이어 명명이 제각각인 GMP 도면에 특히 유효**. 방경계 폐곡선화에 벽추출 로직 활용. 8×A100 학습.

## B. GNN 방타입 분류 (Grade 추론 4번째 소스)

- **Room Classification GNN** (2021, 2108.05947): GraphSAGE 80%/TAGCN 81%, **GCN, GAT는 MLP(66%)보다 나쁨**,
  GraphSAGE/TAGCN은 oversmoothing 강건. 143k샘플. 인접=bbox거리<0.03. → 백본=GraphSAGE. 80%는 대데이터.
- **SAGE-E** (AiC2022, S0926580521004908, **코드공개** github ZijianWang1995/SAGE-E): GraphSAGE에 엣지피처 결합,
  79%/F1 0.79. 224아파트/9클래스. **엣지피처가 노드피처보다 강력**, **피처설계>데이터양**(51샘플도 74%).
  → 실분류 baseline. 관계(access/enclosure) 엣지 모델링이 GMP ACC 핵심.
- **IFC GNN** (Energies2022, energies-15-02937): **가장 직접적.** 벽→방폴리곤=convex hull 차집합(shapely).
  accessibility 그래프=접함/문/개구부/계단 **4종 엣지**(거리threshold보다 GMP에 우월). WGCN(자기/이웃 가중분리).
  8모델/320방 → inductive **50%**(WGCN)/64%(클래스병합). → 교훈: **클래스축소, GMP고유피처(차압/기류/HEPA/
  재실/gowning), 건물단위 train/test분할(층누수방지)**. 소데이터 현실의 직접 대응서.

## C. 규정 자동검증 ACC (Stage 2 - 우리 엔진의 학술 계보)

- **RASE** (CIB W78 2011, w78-2011-Paper-45): 규정문장을 **R**equirement/**A**pplicability/**S**election/**E**xception
  4연산자 + phrase{topic,property,comparator,target,unit}로 마크업. Translate/Transform/Transfer 3원칙(명확→직접,
  모호→재작성, 성능기반→전문가라우팅). → **규칙 YAML 스키마의 1순위 골격**(별표17을 R/A/S/E로 분해),
  근거추적성(유도라인)의 원조. 15년째 후속연구가 계승하는 정전(canon).
- **Peng&Lin KG** (SciRep2023, s41598-023-34342-1): **Neo4j+SPARQL** ACC. 규정을 지식그래프(schema층 온톨로지+
  data층 트리플, CRF+attention NLP추출), BIM→IFCOWL→RDF. **매핑룰(용어이질성해소)+체크룰 분리**.
  **체크룰 4범주**(class1 명시값/class2 파생/class3 구조/class4 해존재). P96.8~98.2%, 3~9초.
  → **우리 Neo4j+규칙엔진의 직접 청사진.** 4범주를 GMP규칙 복잡도 태그로, 매핑룰로 도면라벨↔규제용어 매핑.
- **LLM ACC** (AiC2026, S0926580525007472, 코드X): LLM(GPT-4o)이 규정을 로직변환 없이 직접해석. ACC 4기능
  분해, 규정을 **JSON Schema**계층으로, 의존성식별 F1 1.0, function-calling으로 IfcOpenShell 호출, 97.7%.
  → 규정텍스트→YAML초안 자동생성에 의존성탐지, 절분류 프롬프트 재사용. **한계(비결정성, fail-safe로
  데이터부족을 non-compliant로 뭉갬)가 역설적으로 우리 결정론 판정 노선을 정당화**.
- **PRISMA review** (AiC2026, S0926580526001007): ACC 88편 리뷰. 온톨로지, 그래프 33%/LLM, NLP 33%/rule 20.5%.
  "rule-based가 **auditability(감사가능성)**로 여전히 지배적"(GMP 핵심가치). 추적성, 재검사가 미래요구.
  성능기반, 공간관계 규정 형식화가 전분야 미해결=GMP 기회이자 난제. → 기술선택 지형도, 논문 프레이밍.
- **Wu RevisitACC** (2025): 검사→**수정(post-check adaptation)**. Solihin-Eastman 규칙 4-class, property를
  기하/의미/위상 3분류 + dependency(spatial/connectivity/access/enclosure). → 우리 Track F(repair)의 이론틀.
- **Ying&Sacks** (CIB W78 2024, w78-2024-paper_59): LLM **ReAct 에이전트** 자율검사(RevitCopilot), tool-calling.
  단일 정량규칙 PoC. **비결정성, 데이터유출, 단일객체수정 한계**. → 리포트에 수정제안, 단 판정은 결정론에.
- **ML in ACC SLR** (ITcon2025, 2025_02-ITcon-Alnuzha): 71편 SLR. 규정해석(NLP) 60%+. **3대 난제: scalability
  59/71, 데이터부족 42/71, 벤치마크부재 29/71**. ML 비결정성은 거의 미논의(공백). GNN, LLM 미탐색=신규성.
  결론=rule+ML 하이브리드. → 우리 리스크문서와 직결, 자체 벤치마크(기준값 검증)가 내부 벤치.

## D. 생성 - 방(실) 레벨 레이아웃 (Stage 3)

- **House-GAN** (ECCV2020, 2003.06988, 코드공개): Conv-MPN 관계형GAN, 버블다이어그램→방 bbox.
  compatibility=graph edit distance. 직사각, 무크기, 무문. → 그래프제약 생성 원조, compat지표=규제인접준수율.
- **Graph2Plan** (TOG2020, 2004.13204, 코드공개): **경계+그래프→벡터평면**, retrieve-and-adjust(RPLAN검색+조정),
  기하손실(coverage/interior/mutex). IoU 0.8. → **고정외곽에 방배치=우리 문제와 정확대응.** 승인도면 템플릿 재사용.
- **HouseDiffusion** (CVPR2023, 2211.13287, 코드공개): 이산(8bit정수좌표)+연속 디퓨전. attention 3종
  CSA(방내)/GSA(전역)/**RCA(제약그래프 연결쌍만=필수인접 강제)**. +67%다양성/+32%compat. → RCA=GMP필수인접 주입통로.
- **GSDiff** (AAAI2025, 2408.16258, 코드공개): junction노드→벽엣지 2단계, **alignment loss**(다진법 이진좌표로
  벽 정렬유도), 폴리곤루프 추출. → 생성기가 대략정렬→CP-SAT repair 부담↓. boundary/topology 인코더 조건.
- **DiffPlanner** (TVCG2025, 2508.13738, 코드X): boundary→node→adjacency→partition **coarse-to-fine** 확산,
  단계별 사용자개입. FID최저. bbox표현→틈 불가피, 조건마다 별도망. → 워크플로 대응 좋으나 이식비용 큼.
- **HypergraphFormer** (2026, 2605.18932, 코드공개): **BSP트리+access graph** 표현, 작은 LLM(Qwen3-4B)+LoRA로
  생성. **겹침, 틈 0(타일링 설계보장)**, 방multiset 정확, **데이터효율(절반), OOD강**(WMR24 벤치 공개), 결정적 편집.
  → **BSP 채택 시 CP-SAT repair 부담 근본감소.** GMP 데이터희소+분포이질에 특히 적합. 비직교벽은 약점.
- **RLVR** (Mila 2026, 2605.14117, **코드공개**): **JSON 폴리곤 표현, SFT(Llama-70B)→GRPO RLVR.** 보상=연결성+
  총면적(동일가중), **겹침/파싱실패=보상0(하드 feasibility)**. compat 8방 94%↓. **보상해킹 실측**(연결성만→방축소).
  8B실패, GPT-4o few-shot 실패. → **우리 검증가능보상의 직접 원형.** 규칙엔진=reward. 하드/소프트 분리 패턴.
- **MedBuild AI** (2025): 3에이전트 neuro-symbolic. **규정계산은 결정론 파이썬 전문가시스템에 격리(환각차단)**,
  LLM은 typology library 안에서만, 하드위상제약(비순환 트리) 프롬프트, **정수그리드 기하커널**(float 불안정회피).
  → 규칙엔진-as-safety 아키텍처. 정량검증 부재가 약점(우리 강점 여지).
- **FloorplanMAE** (2025): MAE 자기지도, 부분→완성(래스터). → 증축(기존동 고정) 스케치보조. 벡터정밀, 규정보장 X.
- **SemLayoutDiff** (2025, 2508.18597, 데이터/코드 페이지 공개): **categorical diffusion으로 하향식 시맨틱맵
  (픽셀=카테고리) 생성**, 건축 룸마스크+room type 조건. **겹침, 경계이탈 표현상 자동방지**, 문/창 반영, 통합모델.
  → GMP "방들이 외곽 겹침없이 타일링"과 맞물림(BSP계열). 래스터→벡터 갭, 후보 존맵 생성+규칙검증으로.

## D2. 생성 - 가구/장비 배치 (Stage 3 하위, 이상탐지)

- **ATISS** (NeurIPS2021, 2110.03675, 코드공개): 순열불변 AR transformer, 방형상 조건부 객체 set 생성.
  **우도기반 failure detection**(저우도=이상 후보). → 장비배치 + **위반후보 자동 플래깅**.
- **DiffuScene** (CVPR2024, 2303.14207, 코드공개): 순서없는 객체 set 확산, **IoU손실(관통억제)**, 완성/재배치/텍스트.
  cross-attn 조건(BERT자리에 제약인코더). → **생성엔진 유력후보.** IoU손실=클리어런스 하드제약을 소프트로.
- **MiDiffusion** (2024, 2405.21066, 코드공개): **이산(라벨 D3PM)+연속(기하 DDPM) mixed diffusion**, floor경계
  조건(PointNet), **재학습없이 completion/rearrange**. → 고정코어(계단/샤프트) 유지한 채 배치=리모델링 시나리오.
- **LEGO-Net** (CVPR2023, 2301.09629, 코드공개): Langevin 반복디노이징으로 **어질러진 배치→정돈(대칭/정렬/등간격)**,
  이동최소화(EMD). → 사람초안을 규칙에 맞게 **정돈/스냅하는 후처리**. 합성규칙 학습(Table-Chair)=합성데이터 선례.
- **LayoutGPT** (NeurIPS2023, 2305.15393, 코드공개): **CSS 구조표현 + training-free LLM** in-context. 경계이탈↓, FID↓,
  단 KL(분포재현) 약함(드문요소 회피). → **소데이터 부트스트랩, 규칙을 프롬프트로 주입, 설명가능.** 정밀기하는 약함.
- **HierRelTriple** (2025, 2503.20289, 코드공개예정): DiffuScene 위에 **미분가능 IoU 계층삼중항손실**(O2R/O2O/C2C,
  Delaunay). 충돌 15%+↓. → 규칙을 **gradient로 주입**(RLVR 비미분+best-of-N의 대안). 객체→기능영역→레이아웃 위계=
  장비→구역→층과 대응.
- **Open-Universe** (2024, 2403.09675): LLM이 좌표 대신 **선언적 DSL 프로그램 생성 → 미분가능 CSP 솔버로 배치**,
  에러 4분류 자동교정(contradiction subgraph 탐지). → **LLM=제약프로그램, 솔버=좌표** 분업의 정석. 규칙위반 자동검출.
- **COFS** (2022, 2205.14657, 조건부공개): BART 인코더-디코더, **임의 속성 부분집합 conditioning**([MASK]+cross-attn).
  우도기반 이상탐지. → "면적/위치 고정(규정), 나머지 자동" 부분제약 생성에 직결.
- **PlanIT** (SIGGRAPH2019, planit, **코드공개**): 관계그래프(support/12종 공간엣지) plan → **CSP+neurally-guided
  backtracking** instantiate. 제약완화(2차 점증), Most-Constrained-Variable. → **규정을 그래프제약으로 인코딩+
  백트래킹 repair.** 단 빈공간(복도) 1급모델링 부재가 GMP 통로확보에 약점.

## E. 제약 솔버 (Track A/F 백엔드)

- **CDCL+VSIDS for FLP** (2026, 2512.18034 = "Conflict-Driven Clause Learning..."): 격자 이산배치. **CDCL-SAT는
  feasibility 판정이 CP-SAT/MILP보다 1~2배수 빠름(준상수), MILP는 지수폭발.** CDCL은 목적함수 최적화 불가 →
  CP-SAT가 최적화. **Warm-Start 하이브리드(CDCL 즉시 feasible hint→CP-SAT upper bound)로 전역최적 100% 달성+가속.**
  인접/이격/차단셀/다층 CNF 인코딩(cardinality O(m log m)). → **우리 솔버 아키텍처 정당화:** feasibility=CDCL,
  최적화=CP-SAT(OR-Tools, 이미 스택). 생성초안→CDCL feasibility→CP-SAT 정련 3단 파이프라인.
