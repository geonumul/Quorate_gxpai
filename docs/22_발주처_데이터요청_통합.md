# 발주처 데이터 요청서 (통합, 발주처 전달용, 2026-07-03)

발주처에 요청할 데이터를 한 곳에 정리한다. **목적 A(지금 검사기 활성화)**는 현 납품물을 완성하는 데
필요한 것, **목적 B(상세도 생성 학습)**는 후속 자동생성 단계용이다. 두 목적 모두 **핵심 원칙:
PDF, 변환 DXF 가 아니라 원본 DWG + XREF 원본 + 레이어/블록 표준.**

참고: 아래 "CAD 표준, 블록 라이브러리"는 **사무소마다 전부 다르다.** 그래서 이 프로젝트 도면을 실제로
그린 **그 설계사무소의 표준, 블록**을 받아야 한다(범용 표준은 없음. 교수님 사무실 예시는 "이런 종류의
자산"을 보여준 참고일 뿐). 우리 엔진은 **프로파일 기반**이라 사무소별 표준을 프로파일로 등록해 그
사무소 스타일로 생성한다("하나의 표준" 가정 없이 사무소별 적응). 여러 사무소 데이터가 쌓일수록
공통 패턴 학습이 가능해지지만, 기본 단위는 "사무소별 표준"이다.

---

## A. 지금 필요 (검사기 활성화, 현 납품물 완성)

우선순위대로. 각 항목 = 무엇을 / 왜(무엇이 풀림).

> **정정(2026-07-03 검증)**: 우리가 받은 DXF 는 XREF 가 이미 **bound(파일에 박힘)** 상태였다
> (살아있는 외부링크 0, 바인드 흔적 16, 벽 기하는 모델스페이스에 직접 60만+ 엔티티로 존재).
> 즉 **벽 기하는 이미 손에 있어 별도 XREF 파일이 필수는 아니다.** 다만 실제 파일이 여러 시트 타일링 +
> 잔재 + 정크가 섞인 현장 CAD 난장판이라, 원하는 층만 잘라 경계를 조립하는 건 엔지니어링 난제로 남는다.
> **깔끔한 XREF 원본**은 그 추출 난이도를 크게 줄여주므로 "필수"에서 "있으면 좋음"으로 하향한다.

| # | 요청 데이터 | 왜 필요 (무엇이 풀림) |
|---|---|---|
| A1 | **(선택) 층별 깨끗한 벽 원본(XREF 원본 또는 층 분리 DWG)** | 벽 기하는 이미 bound 로 확보됨. 원본은 경계, 면적 정밀 추출의 공수를 줄여줌(난장판 파일 untangle 불필요). 없어도 추출 시도는 가능 |
| A2 | **청정등급(Grade) 도면** | 방별 A/B/C/D 등급. 현재 전부 비어 있음. 등급 인접 금지(ADJ-001), 갱의 체인(ADJ-002), 등급 기반 차압 규칙이 이걸 없으면 못 켜짐 |
| A3 | **화살표 의미 1줄 확인** - "차압 화살표의 화살촉은 저압(낮은 압력) 쪽을 가리키는 게 맞습니까?" | 압력 역전 규칙(PRES-001) 활성화. 틀리면 규칙이 정반대라 반드시 확인 필요 |
| A4 | **TA 값 단위 확인 + 실제 차압(Pa) 수치 위치** | TA 값은 분석상 풍량(CMH)이지 차압(Pa)이 아님. 차압 기준값 규칙(PRES-002)엔 실제 Pa 수치가 도면/설계서 어디 있는지 확인 필요 |
| A5 | **1, 2층 차압 도면** | 현재 3, 4층 차압도만 있음. 1, 2층 압력 검사 불가 |
| A6 | **GMP 컨설턴트 검수** | 규칙 근거 조항(별표17 등), 등급 서열(grade_rank), 금지 인접쌍(forbidden_pairs), 기준 차압값. 전부 "검수대기"라 규칙이 잠정 상태 |
| A7 | **원본 DWG** (변환 DXF 아님) | 우리가 받은 변환 DXF 는 XREF, 좌표계가 깨져 있었음(여러 시트가 한 파일에 섞여 좌표 혼재). 원본 DWG + XREF 라야 깨끗 |
| A8 | **도면 라벨 ↔ 규제 용어 매핑** | 예: "탈의실"이 어느 등급 전이인지, "전실"이 에어락인지. 규칙 적용의 의미 매핑 |

## B. 후속 (상세도 자동생성 학습용)

목적: AI가 상세도를 거의 완성 수준으로 생성 → 자동 규정검토 → 사람 최종 체크+날인.

| # | 요청 데이터 | 왜 필요 |
|---|---|---|
| B1 | **여러 프로젝트/시설의 전체 도면 세트 (원본 DWG)** + 각 **XREF 소스 파일** | 생성 모델 학습 본체. 시설 1개(N=1)로는 불가. 평면, 청정도, 차압, 동선, HVAC, 전기, 배관, 소방, 단면, **상세도**까지 |
| B2 | **CAD 표준 (이 도면을 그린 그 사무소 것)** - 레이어 표준, 선유형, 출력 펜 위계, 문자 스타일 | 사무소마다 다름. 그 사무소 표준을 프로파일로 등록해야 그 스타일로 생성 |
| B3 | **블록/심볼 라이브러리 (.dwg, 그 사무소 것)** | 문, 창, 기구, HVAC 그릴, 기둥, 계단 등 표준 심볼. **그 사무소 블록을 재사용해야 상세가 실제와 동일** |
| B4 | **표준 상세도 (디테일 라이브러리)** | 벽 단면, 패널 조인트, 문/창호, 바닥/천장 상세. 배치→상세 자동화의 재료 |
| B5 | **표제란(도면 양식) 템플릿** | 시트 양식 자동 생성 |
| B6 | **요구조건 ↔ 도면 쌍** - 실 목록, 면적표, 실별 데이터시트(등급, 차압, 환기, 마감), 공정 흐름도, 장비 리스트 | 조건부 생성의 입력측. 쌍이 있어야 "요구→도면" 학습 |
| B7 | **도면 수정 이력 (before/after)** + 검토 의견, 마크업 + 준공도(as-built) | "전문가가 무엇을 고치는가" = 사람 개입을 학습해 줄이는 최고급 데이터 |
| B8 | **적용 규정 목록, 해석 + GMP 검수 기준** | 자동 규정검토(심판)의 근거 |

|---|---|---|
| C1 | **AI 학습, 파생생성 사용 동의 (서면)** | 도면 저작권이 원 설계사무소일 수 있음. 학습, 변형, 생성 권리 명문화 |

## 발주처에 특히 강조할 3가지
1. **PDF 말고 원본 DWG** (+ XREF 원본). 변환본은 좌표계, 블록이 깨져 쓰기 어렵다.
2. **CAD 표준(레이어, 펜, 문자) + 블록/심볼 라이브러리** - "실제와 똑같은 상세"의 열쇠.
3. **도면 수정 이력** - 사람 개입을 줄이는 학습의 최고급 재료.

## 당장 회신 하나로 풀리는 것 (가장 값싼 요청)
- **A3(화살표 의미), A4(TA 단위)** 는 각각 한 줄 답이면 되고, 이것만으로 압력 규칙 검토가 크게 진전된다.
- **A2(Grade 도면)** 하나가 등급 규칙(ADJ) 전부를 연다.
- 경계, 면적은 A1(XREF) 없이도 이미 있는 bound 기하로 추출 시도 가능(단 공수 큼). A1 은 그 공수를 줄이는 선택지.
